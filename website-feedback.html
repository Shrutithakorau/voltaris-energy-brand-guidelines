Website review · August 2026

Voltaris Energy — Website Feedback

Notes on voltarisenergy.com.au, ordered roughly by impact.

Brand guidelines GitHub repo

High priority

  1. Price mismatch — Meta description says systems from $22,990; homepage packages show from $7,000 / $8,000. Align one source of truth and clarify what “from” includes.
  2. Rebate claims are vague — Tighten copy and add clear eligibility disclaimers.
  3. Lead form is too long / off-brief — Split solar quote vs other VEU-style upgrades.
  4. Duplicate / weak rebate section — “Available Battery Rebates” repeats the section intro.
  5. Social proof is thin — Only two residential testimonials; add reviews, photos, or case studies.
  6. No structured data / thin trust footer — Add JSON-LD, ABN, address, email, licence details.

Content & messaging

  1. Copy sounds AI-padded — Trim repeated “today / now / always.”
  2. Headline spacing quirks — Check joins like “withSmarter” / “Batteryfor.”
  3. Capitalisation inconsistency — e.g. “Experienced installation Team.”
  4. Package CTAs feel unfinished — “Get a free quote ?”
  5. “Australia-wide” vs Melbourne-first — Back national claims with proof.
  6. Savings calculator trust — Show assumptions behind ROI numbers.
  7. Commercial page polish — Editorial pass needed.
  8. Privacy link in consent — Point to a real privacy policy page.

UX / conversion

  1. Too many competing CTAs — One primary action per section.
  2. Make phone persistent on mobile — Sticky click-to-call for 0430 741 441.
  3. Partner logos without context — Add “installed & supported by Voltaris.”
  4. FAQ is short — Add rebates, phase, existing solar, backup limits, quote timing.
  5. Only two package cards — Add a third tier or custom path.

Technical / accessibility / SEO

  1. Title vs H1 mismatch — Align primary message.
  2. www vs non-www — One preferred host + redirect.
  3. Empty image alts — Meaningful alt on product/hero images.
  4. No skip-to-content link
  5. Confirm analytics — GA4/GTM/ads pixels.
  6. No blog/guides — Helpful for SEO and education.

Brand / design

  1. Strong visual system — Keep yellow CTA, navy, cream, pill nav.
  2. Cream + muted grey contrast — Check WCAG.
  3. Motion — Respect prefers-reduced-motion.

Biggest wins

Reconcile pricing, shorten the quote form to solar/battery, strengthen trust (reviews + business details), and clean rebate/disclaimer copy.
